## ✨ Fitur-Fitur Utama Website

### 🌐 1. Area Publik (Public School Portal)

#### 🏠 Beranda (Home Page)
- **Hero Slider & Dynamic Banner**: Menampilkan pengumuman SPMB/PPDB aktif yang terhubung dinamis dengan pengaturan panel admin.
- **Sambutan Kepala Sekolah**: Paparan visi kepemimpinan dan komitmen pendidikan berbasis kearifan lokal *Sakai Sambaiyan*.
- **Widget Statistik Interaktif**: Rekap siswa aktif (850+), tenaga pendidik (54 orang), fasilitas ruang kelas (24 rombel), dan tingkat serapan PTN (94,8%).
- **Program Unggulan Sekolah**: Program *Sekolah Model Pembelajaran Mendalam & Koding*, Pembinaan Intensif OSN, serta Gerakan Sekolah Berbudaya Lingkungan (Adiwiyata).
- **Pratinjau Berita & Galeri**: Akses cepat ke artikel prestasi dan foto kegiatan sekolah terbaru.

#### 📖 Profil Sekolah (Profile Page)
- **Sejarah & Milestone**: Dokumentasi perjalanan sekolah dari awal berdiri tahun 1991 hingga penetapan resmi sebagai Sekolah Unggul Provinsi Lampung.
- **Visi, Misi & 5 Core Values**: Prinsip Religius, Cerdas, Berkarakter, Berwawasan Lingkungan, dan Gotong Royong Sakai Sambaiyan.
- **Tabel Data Pokok & Legalitas**: Informasi operasional lengkap, nomor SK, akreditasi, luas tanah, dan daya listrik.
- **Direktori Guru & Tenaga Kependidikan**: Daftar profil pimpinan, wakil kepala sekolah, dewan guru pengampu mata pelajaran, gelar akademik, dan foto resmi.
- **Fasilitas Kampus**: Pratinjau laboratorium komputer koding, laboratorium IPA (Fisika, Biologi, Kimia), panggung seni budaya, dan sarana olahraga.

#### 📰 Warta & Berita (News & Articles)
- **Kategori Berita**: Prestasi Siswa, Akademik, Kegiatan Sekolah, dan Pengumuman Resmi.
- **Live Search & Filter**: Pencarian artikel berdasarkan kata kunci judul/isi berita secara instan.
- **Kartu Artikel Responsif**: Informasi tanggal publikasi, nama penulis, estimasi waktu membaca (*read time*), dan cover foto kegiatan.

#### 🏆 Ekstrakurikuler (Extracurricular Directory)
- **Katalog Ekskul Lengkap**: Paskibra, Sanggar Seni Tari Lampung, Pramuka, Rohis, PMR, Taekwondo, KIR Sains, Jurnalistik, dan Olahraga Prestasi.
- **Pencarian Cepat**: Filter pencarian real-time untuk menemukan nama ekskul, jadwal latihan, dan lokasi.
- **Profil Ekskul & Prestasi**: Nama pembina, jadwal rutin per minggu, lokasi latihan, dan rekam jejak juara tingkat Kabupaten/Provinsi/Nasional.

#### 📸 Galeri Multi-Media (School Gallery)
- Dokumentasi foto resolusi tinggi terkait upacara bendera, sholat dhuha berjamaah, apel anti-bullying, dan kejuaraan siswa.
- Filter kategori: *Profil*, *Fasilitas*, *Kegiatan*, dan *Prestasi*.
- Modal penampil gambar (*Lightbox Preview*) dengan deskripsi detail.

#### 🎓 PPDB & SPMB Online (Penerimaan Peserta Didik Baru)
- **Validasi Otomatis Jadwal Gelombang**:
  - Pendaftaran **otomatis terkunci** jika tanggal saat ini belum sampai (*Belum Dibuka*) atau sudah lewat (*Sudah Berakhir*).
  - Badge status *real-time* (Hijau: Sedang Dibuka, Biru: Belum Dibuka, Merah: Sudah Berakhir).
  - Tombol aksi cerdas: Mengarahkan langsung ke gelombang aktif dan menonaktifkan pendaftaran untuk gelombang non-aktif.
- **4 Jalur Penerimaan Siswa**:
  1. *Jalur Prestasi Sekolah Unggul* (Kuota: 35%)
  2. *Jalur Zonasi Domisili* (Kuota: 45%)
  3. *Jalur Afirmasi KIP / PKH* (Kuota: 15%)
  4. *Jalur Mutasi / Tugas Orang Tua* (Kuota: 5%)
- **Formulir Registrasi Calon Siswa Terpadu**:
  - Validasi NISN 10 digit angka, nilai rata-rata rapor, kontak WhatsApp aktif, dan peminatan jurusan.
  - Dropdown jalur pendaftaran otomatis membatasi pilihan ke jalur yang sedang buka saja.
  - Banner peringatan dinamis jika gelombang yang dipilih tidak aktif.
- **Unggah 4 Berkas Dokumen Wajib**:
  1. Kartu Keluarga (KK minimal 1 tahun)
  2. Akta Kelahiran Calon Siswa
  3. e-KTP Orang Tua / Wali
  4. Ijazah atau Surat Keterangan Lulus (SKL) SMP
  - Dilengkapi fitur **Client-Side Image Compression** otomatis (<120KB) untuk memastikan hemat penyimpanan dan cepat diunggah.
  - Modal pratinjau (*preview*) dokumen sebelum dikirim.
- **Pernyataan Keabsahan & Cetak Bukti Registrasi**:
  - Kotak centang persetujuan keabsahan data hukum sebelum tombol kirim aktif.
  - Nomor registrasi unik resmi (contoh: `REG-2026-001`) yang dapat disimpan dan dicetak sebagai bukti pendaftaran.

#### 📞 Kontak & Pengaduan (Contact Page)
- Formulir pengiriman pesan/konsultasi langsung bagi wali murid dan masyarakat.
- Peta lokasi interaktif (Google Maps) kampus SMAN 2 Kalianda di Desa Kedaton.
- Hotline resmi panitia PPDB, email sekolah, dan tautan akun media sosial.

### 🔐 2. Portal Pengelola CMS (Admin Panel)

Akses khusus bagi staf pengelola dan Humas TI sekolah melalui rute `/admin/login` dengan fitur:

- **Autentikasi Aman & Proteksi Rute**: Sesi login berbasis token lokal terproteksi.
- **Sidebar Desktop Tetap (*Stationary Fixed Sidebar*)**: Sidebar tetap kokoh di posisinya dan tidak ikut bergulir saat admin melakukan *scroll* pada tabel data yang panjang.
- **Top Header Navbar Terpadu**:
  - Informasi profil admin aktif (`AD` - Administrator Humas & TI / Super Admin CMS).
  - Tombol cepat **Buka Web Publik** (buka di tab baru).
  - Tombol **Keluar Portal CMS** dengan dialog konfirmasi logout yang estetik.
- **Dashboard Overview (`/admin`)**:
  - Rekap statistik pendaftar PPDB, berita terbit, total ekskul, dan persentase kuota terisi.
  - Daftar pendaftar terbaru dengan status verifikasi cepat.
- **Manajemen Berita (`/admin/berita`)**:
  - Tambah artikel baru, edit isi, ubah kategori, upload foto sampul, dan hapus artikel lama.
- **Manajemen Ekstrakurikuler (`/admin/ekstrakurikuler`)**:
  - Kelola daftar ekstrakurikuler, pembina, jadwal latihan, dan capaian piala penghargaan.
- **Manajemen Pendaftar PPDB (`/admin/ppdb`)**:
  - Tabel master pendaftar dengan fitur pencarian instan (nama, NISN, ID pendaftar, asal SMP).
  - Filter pendaftar berdasarkan status (*Menunggu Verifikasi*, *Terverifikasi*, *Berkas Perlu Dilengkapi*) dan jalur pendaftaran.
  - Modal detail pendaftar lengkap: rincian nilai rapor, identitas wali, dan pratinjau 4 dokumen unggahan (KK, Akta, KTP, Ijazah).
  - Ubah status verifikasi siswa dan hapus data.
- **Manajemen PPDB & SPMB (`/admin/ppdb-settings`)**:
  - Atur jadwal gelombang pendaftaran dengan datepicker tanggal buka (`startDate`) dan tanggal tutup (`endDate`).
  - Sakelar operasional utama: Buka / Tutup pendaftaran online secara global dalam satu klik.
  - Sunting teks pengumuman berjalan beranda dan catatan persyaratan berkas wajib secara *real-time*.
- **Pengaturan & Mode Demo (`/admin/pengaturan`)**:
  - Monitoring kapasitas penyimpanan browser (*LocalStorage Engine*).
  - Fitur **Factory Reset / Reset Data Demo** untuk mengembalikan seluruh konten ke data awal jika diperlukan.

## 🚀 Panduan Memulai (Quick Start)

### 📋 Prasyarat
Pastikan komputer Anda telah terinstal:
- **Node.js** (versi 18.0 atau lebih baru disarankan)
- **npm** (versi 9.0 atau lebih baru)
- **Git**

### 💻 1. Clone & Instalasi Dependensi
```bash
# Clone repositori ini
git clone https://github.com/USERNAME_ANDA/NAMA_REPO.git

# Masuk ke direktori proyek
cd NAMA_REPO

# Install seluruh paket dependensi
npm install
```

### ⚡ 2. Menjalankan Server Pengembangan Lokal
```bash
npm run dev
```
Aplikasi akan berjalan di alamat:
- **Lokal**: `http://localhost:5173`
- **Network (Akses dari HP di WiFi yang sama)**: `http://IP_KOMPUTER_ANDA:5173`

### 📦 3. Membuat Bundle Produksi (Build)
```bash
npm run build
```
File siap rilis akan terkompilasi ke dalam folder `/dist` dengan optimasi *minify* dan *tree-shaking*.

## 🌐 Panduan Pengujian di Perangkat HP (Same WiFi)

Untuk menguji tampilan responsif website ini langsung di smartphone menggunakan jaringan Wi-Fi yang sama:
1. Pastikan komputer dan smartphone terhubung ke **jaringan Wi-Fi yang sama**.
2. Jalankan server dengan perintah:
   ```bash
   npx vite --host
   ```
3. Perhatikan baris **Network** pada terminal (misal: `http://192.168.1.15:5173`).
4. Buka browser di HP Anda (Chrome/Safari), lalu ketikkan alamat IP tersebut.

## 🚢 Panduan Deployment (Hosting)

Website ini adalah Single Page Application (SPA) berbasis client-side rendering yang sangat ringan dan siap di-deploy secara gratis di berbagai platform hosting modern:

### Opsi A: Vercel (Disarankan)
1. Hubungkan repositori GitHub Anda ke akun [Vercel](https://vercel.com).
2. Biarkan setting build otomatis:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Tambahkan file konfigurasi `vercel.json` untuk rewrite rute SPA jika diperlukan:
   ```json
   {
     "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
   }
   ```

### Opsi B: Netlify
1. Hubungkan repositori ke [Netlify](https://netlify.com).
2. Set build command: `npm run build` dan publish directory: `dist`.
3. Buat file `public/_redirects` dengan isi:
   ```text
   /*    /index.html   200
   ```
